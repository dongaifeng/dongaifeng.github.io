postCss原理

Author: Dongaifeng Date: 2026-03-06,  10:48:29

CSS 语法转换的工具，自定义 CSS 之类的语法，这些语法可以被插件理解和转换。PostCSS 的工作原理是将 CSS 解析成抽象语法树（AST），然后通过一系列插件对 AST 进行处理，最后再将 AST 转回成 CSS。

插件

官网插件列表

  • postcss-px-to-viewport 用于将 CSS 中的像素单位（px）转换为视窗单位（vw）
  • postcss-pxtorem 将像素单位转换为 rem。
  • autoprefixer 使用 Can I Use 中的数据为你添加浏览器前缀
